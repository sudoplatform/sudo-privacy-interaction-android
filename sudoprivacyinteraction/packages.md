# Module sudoprivacyinteraction

Sudo Platform Privacy Interaction SDK for Android.

With this SDK you can:
* connect a virtual presence to a provider using an OAuth authorization code or a refresh token, and disconnect it when no longer needed
* rescan and list a user's virtual presences to keep their connected accounts up to date
* discover and list the data holders associated with a virtual presence
* retrieve and list the privacy analysis results for a virtual presence
* subscribe to receive notification of virtual presence, data holder, and analysis result state changes

# Package com.sudoplatform.sudoprivacyinteraction.client

The main entry point of the Sudo Platform Privacy Interaction SDK for Android. Use the `SudoPrivacyInteractionClient.builder()`
to construct an instance of the Sudo Platform Privacy Interaction SDK.

# Package com.sudoplatform.sudoprivacyinteraction.types

Types used by the methods of the Sudo Platform Privacy Interaction SDK.
