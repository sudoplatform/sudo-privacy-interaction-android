OrganizationAnalysis

data class OrganizationAnalysis(val id: String, val domain: String, val status: AnalysisResultStatus, val lastAnalyzedAt: Date, val data: AnalysisResultData? = null, val owner: String, val version: Int, val createdAt: Date, val updatedAt: Date) : Parcelable

The Sudo Platform SDK representation of a shared, domain-keyed privacy analysis of an organization.

The same underlying analysis is returned to every caller asking about the same domain; it carries only organization-generic signals. id equals the analyzed domain and owner is the requesting caller.
